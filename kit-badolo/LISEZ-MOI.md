# Kit de marque · christian thomas badolo

Ce kit contient tous les fichiers de ta marque. Chaque visuel existe en plusieurs couleurs et en plusieurs formats. Utilise le fichier qui correspond à ton besoin, sans jamais le déformer ni changer ses couleurs.

## Quel format utiliser ?

| Format | Usage |
|---|---|
| **SVG** | Vectoriel et modifiable. Pour Canva, Figma, Illustrator et le web. |
| **PDF** | Vectoriel, pour l'imprimeur et Word. |
| **PNG** | Image avec transparence possible. Pour PowerPoint, les réseaux et les documents. |
| **JPG** | Image légère sans transparence, pour les bannières à téléverser. |
| **MP4** | Vidéo pour LinkedIn, Instagram, WhatsApp et les présentations. |
| **WebM / MOV** | Vidéo à fond transparent, à incruster dans un montage (CapCut, Premiere). |

## Les couleurs de logo

Le nom de chaque fichier se termine par sa déclinaison de couleur.

| Nom dans le fichier | Rendu | Quand l'utiliser |
|---|---|---|
| `marine` | Logo clair sur fond marine | **Version principale** |
| `clair` | Logo marine sur fond gris clair | Fonds clairs |
| `blanc` | Logo marine sur fond blanc | Documents, CV, Word |
| `noir` | Logo blanc sur fond noir | Vidéo, événements |
| `orange` | Logo marine sur fond orange, point blanc | Occasionnel, pour un temps fort |
| `transparent-marine` | Logo marine sans fond | À poser sur un fond clair |
| `transparent-blanc` | Logo blanc sans fond | À poser sur une photo ou un fond sombre |
| `mono-noir` / `mono-blanc` / `mono-marine` | Une seule couleur | Gravure, tampon, impression en une couleur, fax |

## Modifier les gabarits

Dans les fichiers **SVG** de `04-gabarits/`, le texte est éditable. Importe-les dans Canva ou Figma, puis remplace les textes d'exemple (« Ta citation ici », « +00 % »…). Les PNG du même dossier sont de simples aperçus.

La police utilisée est **Inter Display**, gratuite sur Google Fonts. Installe-la sur ton ordinateur pour que les SVG s'affichent correctement.

## À compléter par toi

- **Carte de visite et signature e-mail** : remplace « Ton titre », le téléphone et l'adresse e-mail.
- **Signature e-mail** : héberge `monogramme-signature-240.png` à une adresse publique et remplace `URL_DU_LOGO` dans `signature.html`. La marche à suivre est au début du fichier.
- **Impression** : les fichiers sont en couleurs écran (RGB). Les valeurs CMJN figurent dans la charte. Demande une épreuve à l'imprimeur.
